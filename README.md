## 문서

### 로컬에서 실행하기

로컬에서 테스트하려면 터미널에서 다음을 실행하세요:

1. 로컬에 저장소 복제
2. `bundle install`
3. `bundle exec jekyll serve`
4. 브라우저에서 `localhost:4000` 열기

### 사용자 정의하기

먼저 저장소를 자신의 계정으로 포크하고 싶을 것입니다. 그런 다음 로컬에 복제하여 사용자 정의하거나, GitHub 웹 에디터를 사용하여 사용자 정의하세요.

### GitHub Pages에 무료로 게시하기

[GitHub Pages](https://pages.github.com/)는 GitHub 계정으로 무료로 호스팅해줍니다. `gh-pages` 브랜치를 사용하고 있는지 확인하면, 사이트가 자동으로 `yourusername.github.io/resume-template`에서 사용할 수 있게 됩니다 (원한다면 저장소 이름을 resume로 바꿔서 `yourusername.github.io/resume`에서 사용할 수 있도록 할 수 있습니다). 사용자 정의 도메인에서 사용하고 싶다면 CNAME도 추가할 수 있습니다...

### 자신만의 도메인 이름으로 설정하기

사용자 정의 도메인으로 GH Pages 사이트를 설정하려면, 해당 주제에 대한 [GitHub 도움말 사이트의 지침](https://help.github.com/articles/setting-up-a-custom-domain-with-github-pages/)을 따르세요.
